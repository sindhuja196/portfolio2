# Sindhuja R — Portfolio

React + TypeScript + Vite + Tailwind CSS portfolio.

## Run
```
npm install
npm run dev        # http://localhost:5173
npm run build      # outputs to dist/
npm run preview    # test the production build
```

## Edit your content
- Text, projects, skills, links: `src/App.tsx`
- Styles and animations: `src/index.css`
- Images, resume and favicon: `public/` (resume: `public/assets/Sindhuja-R-Resume.pdf`)
- Page title and description: `index.html`

## Deploy
Upload the `dist/` folder to Netlify, or import the repo into Vercel
(build command `npm run build`, output directory `dist`).
